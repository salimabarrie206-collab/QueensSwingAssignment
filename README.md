# QueensSwingAssignment

# Java Swing First Individual Assignment

This project is a Java Swing desktop application developed for my Java Swing First Individual Assignment.

The application demonstrates the use of Java Swing GUI components, object-oriented programming concepts, and basic event-driven functionality.

# Objectives

- Develop a graphical user interface using Java Swing.
- Demonstrate the use of JFrame, JPanel, and JLabel.
- Apply inheritance and constructor concepts.
- Implement a custom application icon using ImageIcon.
- Add interactive functionality to change the displayed text.
- Add functionality to change the panel background colour.
- Design a user interface wireframe using Figma.
- Test and document the completed application.

# Technologies Used

- Java
- Java Swing
- IntelliJ IDEA
- Figma
- GitHub

# Features

# Welcome Interface
The application displays a welcome message together with a custom crown application icon.

# Change Text
The Change Text button changes the welcome message displayed on the screen.

# Change Background
The Change Background button changes the background colour of the main panel.

# Custom Icon
A crown image is implemented as the application's window icon using ImageIcon.
